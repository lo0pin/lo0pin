# **Hey there 👋**

## About Me

I’m **Julian** — an electronics enthusiast, curious coder, sailor, and maker of small systems that try very hard to behave sensibly.

I build things with **code, electronics, craft, and words**: from Arduino weather displays and Raspberry Pi logging experiments to small web tools, Meshtastic nodes, 3D-printed enclosures, and a growing static website that documents the whole workshop as it evolves.

What started as tinkering with microcontrollers has become a way to understand how things **measure, communicate, store, fail, recover, and occasionally surprise you**.

Most of my projects live somewhere between:

- embedded systems
- sensor data
- lightweight web development
- field experiments
- sailing and navigation
- and the quiet joy of making something work after it absolutely refused to

Still learning. Still breaking things. Slightly more systematically now.

## My Coding Philosophy

> *“Elegance is not when there’s nothing more to add,  
> but when there’s nothing left to take away.”*  
> — Antoine de Saint-Exupéry

I’m still learning what elegance in code really means.

For now, I try to make each project:

- a little clearer
- a little more robust
- a little easier to understand later
- and a little less dependent on blind hope

Good code should not feel like a magic trick.  
It should feel like a well-labeled switchboard.

## What I Like Building

I enjoy projects that connect the physical and the digital world:

- sensors that turn weather into data
- displays that make tiny histories visible
- radios that whisper across hills
- websites that document instead of merely decorate
- tools that solve small, real problems
- systems that are simple enough to understand and stubborn enough to be useful

The best projects, to me, are not flashy.  
They are **small, thoughtful, slightly over-engineered, and alive**.
